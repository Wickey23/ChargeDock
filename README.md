# ChargeDock Landing Page

This repository contains a simple static landing page for **ChargeDock**, a fictional electric vehicle charging service. The page is built with plain HTML, CSS and a bit of JavaScript for smooth scrolling.

## Getting Started

Open `index.html` in a browser to view the site locally:

```bash
open index.html # macOS
# or
xdg-open index.html # Linux
```

No additional build steps or dependencies are required.

## File Overview

- `index.html` – main landing page markup.
- `style.css` – basic styling for layout and colors.
- `script.js` – small script for smooth scroll navigation.

Feel free to customize the content and styles to match your project.
